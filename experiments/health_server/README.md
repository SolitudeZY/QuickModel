## 本地适配

`lab.py` 使用进程内上游 API，只暴露固定实验操作。管理/API Key 不送到浏览器。凭据保存失败直接失败，禁用上游明文回退。实验未使用上游 Web 仪表盘，也未启用 AI 或定时采集。最近 7 天包含今天，按 Asia/Shanghai 计算；上游具体时间口径和睡眠结果仍待真实数据对照。

扫码需要支持小米账号扫码的手机 App，例如米家；若手机登录页显示授权内容不符合预期，应取消。二维码由小米账号接口返回，有效期本次验证为 300 秒。二维码生成成功不代表账号登录或健康数据读取成功。
