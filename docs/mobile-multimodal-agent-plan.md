## 技术路线与取舍

手机负责交互、录音、选图、抽帧及系统授权；服务器负责模型请求、健康数据读取、附件持久化和会话记录。模型与语音 API 密钥只留服务器。继续复用桌面 Markdown、背景及协议适配器，不重写原生聊天页面。

语音采用 ASR → 现有聊天 Agent → TTS。第一步是分段录音、识别、生成、播放，后续才加入流式识别、边生成边播和打断。优点是保留现有模型选择及健康能力；代价是串联延迟，不等于实时双工。阿里百炼提供录音识别与语音合成 API，可按服务端配置接入；实际可用模型、区域、工作空间与费用以当前账号能力验证为准，不能由已有聊天密钥直接推定。没有配置时须明确显示未启用。

图片先支持系统选图（包括用户已经截好的屏幕），压缩后上传私有服务器；视觉模型直接理解，不支持视觉的聊天模型通过独立视觉服务获取摘要。不得把图片当普通字符串丢给纯文本模型。会话保存附件引用，Base64 只在调用边界出现。

视频第一步采用短视频稀疏抽帧 + 时间戳 + 视觉模型，必要时独立转写音轨；手机侧限制时长、帧数和图片尺寸，避免小服务器转码占满内存。抽帧适合场景、操作步骤与内容总结，可能漏掉快速动作，不能宣称完整逐帧理解。连续视听交互后续评估 Qwen-Omni-Realtime；它与普通聊天是不同会话和传输协议，需单独验证工具调用、耗电、带宽、回声消除与重连。

## P0：交互修复与输出长度

- [x] 键盘开合只改变前景可视高度；背景保持已有场景，尺寸未改变时不重新生成城市/粒子；相同天气不重置动画。旋转屏幕和真实主题切换仍应生效。
- [x] 历史对话弹窗固定标题、关闭按钮与搜索框，仅列表滚动；系统返回键继续可关闭。
- [x] 最大输出 Token 支持 `0 = 跟随服务商默认`，不再由客户端强加 4096；旧设置保留。解释这是单次回答长度/成本控制，不是上下文长度。不存在无限输出，服务商上限、请求超时依然存在；Anthropic 协议必填上限时使用适配器默认值。
- 验收：反复聚焦输入框与模拟键盘高度变化，Canvas 尺寸和场景不变；长历史滚动后关闭按钮仍可点；设置 0 往返保存且调用参数正确。

## P1：健康聊天和图片

- [x] 显式健康上下文开关与来源/时间提示。开启后每次发送读取服务器最近健康快照，为饮食、运动讨论提供依据；不把云端历史测量称为实时心率。
- [x] 快照包含最近步数、心率测量时间、睡眠记录及缺失状态；无睡眠数据不能视为零睡眠。按次追加不可变上下文，不改写已发送的历史和缓存前缀。
- [x] 第一版采用每轮自动读取健康快照，不依赖模型工具调用能力；读取范围仅为已授权健康数据，不暴露桌面命令执行。建议须区分测量、推测和一般生活方式建议，不能凭单次运动心率作诊断。
- [x] 系统选图、缩略图、移除、上传失败重试、带图发送及历史附件回显；鉴权保护附件，校验 MIME/解码尺寸/大小，不允许客户端任意服务器路径或 URL。
- [x] 图片能力与纯文本模型兼容：独立视觉配置可用才允许回退；不可用时显示明确原因，不能静默忽略图片。
- 验收：合成健康数据测试缺失与时间标注；真实服务小额图文请求验证；取消选图、超大图、鉴权失败、重试幂等、旧会话回显测试。

## P2：语音输入与朗读

- [x] 原生录音权限按需申请，界面显示录音状态、停止/取消；限制单段时长，应用离开前台停止录音。
- [x] 服务器 ASR 接口，识别文字可编辑后发送；TTS 朗读回复、可随时停止，网络失败保留文本。
- [x] 百炼配置存加密配置，复用模型配置导入流程但不把长期密钥放 APK；模型和端点可经 SSH 导入配置；本次已验证现有北京 DashScope 端点，无需迁移工作空间域名。
- [x] 语音回复沿用同一健康/图片聊天链路；播放期间开始录音应停止播放，第一版不声称具备回声消除或全双工。
- 验收：合成音频与真实 API 冒烟；权限拒绝、超时、取消及耳机/扬声器真机体验。自动测试不能代替小米真机录音验收。

## P3：屏幕与短视频

- [x] 系统 MediaProjection 授权后按用户操作截屏；明确共享状态与停止入口。Android 14+ 每次捕获会话重新授权，使用前台服务；不绕过受保护窗口。
- [x] 截屏可附加到下一次文字或语音提问，不无限自动上传屏幕。第一版切到后台时停止录音；尚不支持跨应用持续语音与截屏同时进行。
- [x] 系统选择短视频，先限制 60 秒、最多 12 帧，按时长均匀抽帧并保留时间戳；超过限制要求截短，后续再做场景变化采样。
- [x] 视频可提取的 AAC 音轨执行整段转写；明确显示“抽帧分析”及画面采样时间。不支持的音轨明确标记，仅分析画面。逐字时间对齐尚未实现。
- 验收：含明显时间事件的合成视频、竖屏旋转、受保护截图、撤销共享、应用后台、断网与重复提交。

## 发布与数据兼容

每阶段完成后更新本文实际状态、运行相关回归、构建 APK、验证签名与版本递增。服务端备份后更新，保留设备令牌及已有会话；发现正在生成的请求先等待完成。下载页提供版本及二维码，不把未验证能力标为可用。服务器与旧 APK 保持兼容，新增字段带默认值。

“所有数据同步”仍是独立事项：当前服务器持有手机聊天、导入的桌面历史、模型配置及手机设置；桌面记忆、技能、工具、附件和持续双向同步尚不能宣称已完成。本次不通过覆盖整个配置文件实现同步。

## 0.3.0 实施记录与尚待验收

- P0、P1、P2 已实现；P3 已实现一次截屏与短视频抽帧原型。上方勾选表示代码实现，不表示真机全部验收通过。
- 健康分享默认关闭，在“设置 → 健康聊天”开启。每轮保存不可变快照，关闭后不再采集新快照；已经发出的历史上下文不会被就地删除。
- 图片每次最多 4 张；视频独立批次最多 12 帧。服务器保存私有 JPEG 及会话引用；目前没有附件清理 UI，删除/保留周期待后续加入。
- 语音单次最多 60 秒；可只输入文字，也可勾选自动发送并朗读。第一版最多朗读回复前 600 字，支持取消；没有双工、打断后自动续听与唤醒词。
- 截屏每次系统授权后，应用最小化、5 秒后截一次，返回应用上传到私人服务器并预览；点击发送后模型才接收图片。受保护窗口保持系统行为，旋转/应用区域共享适配仍需真机验证。
- 视频长度最多 60 秒，均匀采样 2–12 帧。AAC 音轨在 900 KB 内时尝试转写；其他编码/过大音轨标记为未转写。尚无逐字时间戳、场景变化采样或实时视频流。
- 自动验证：Python 共 59 项回归通过（服务器 12、协议 19、Agent 8、调用器 20）；Edge 手机尺寸回归通过，包含键盘场景像素保持、长历史关闭、0 Token 保存、图片附件发送、语音结果与视频上下文保留；Android release 构建与 lintVital 通过。
- 真实 API：服务器私有图片上传、原生视觉识别、独立视觉回退、健康快照读取通过。语音 TTS → ASR 使用合成素材验证，不输出个人健康数值或密钥。
- 真机待验收：小米图片方向/选择取消、录音权限与播放、屏幕共享撤销/受保护窗口、短视频解码和网络中断。没有连接 Android 真机，不能把编译和浏览器测试算作上述通过。
- 仍属后续工作：连续语音跨应用协作、实时 Omni 视频、健康工具自主规划、多设备完整双向同步、附件保留管理。此次提供可实验原型，不声称完整自主多模态 Agent 已完成。

- 发布：0.3.0 APK 已使用原签名构建并发布到个人服务器下载页；下载安装文件的 SHA-256 与本地产物一致。服务端更新前已备份数据库、加密配置与服务代码，原设备令牌保留。
