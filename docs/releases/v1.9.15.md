# QuickModel v1.9.15

本次更新修复代码复制失效、拖选时夹带语言标签，以及黄昏晴天下侧栏文字不清晰的问题。

## 代码复制

- 修复点击“复制代码”后剪贴板内容不变的问题。浏览器拒绝写入不支持的 `text/markdown` 格式时，旧版会整次复制失败；本版使用受支持的文本和 HTML 格式，并增加备用复制路径。
- 拖选正文和代码时，排除代码类型标签及复制按钮文字，保留所选代码的缩进、空行和换行；支持反向拖选和部分代码选择。
- 扩大复制按钮的点击区域。复制成功后显示“已复制 ✓”和“复制成功”提示，失败时显示重试提示。模型继续输出、刷新消息气泡时，结果提示仍可见。
- 保留普通输入框和纯正文的原生复制行为。

## 两种复制方式

| 按钮 | 用途 |
| --- | --- |
| 复制代码 | 复制原始代码，不附加语言标签、按钮文字或 Markdown 围栏。 |
| 复制格式 | 为 Markdown 提供带语言标记的围栏代码，同时为 Word 提供不含围栏符号的 HTML 代码块。 |

粘贴到 Word 时，请选择“保留源格式”等富文本粘贴方式。“仅保留文本”会使用剪贴板中的 Markdown 文本，因此会包含围栏符号。不同编辑器根据各自的粘贴策略选择格式。

## 黄昏主题

- 左侧历史会话、项目分组、搜索框及右侧文件操作栏使用浅色文字和深色细阴影，移除晴天时的黑字配浅色阴影。
- 文件增删计数改为浅绿色和浅红色。
- 保持现有面板背景和透明度，保留雨天、雷暴下的浅色文字。
