# QuickModel v1.9.16

本次更新支持由主模型直接理解图片，修复图片撤回、重试时丢失附件的问题，并调整 Windows 更新器的关闭顺序。

## 原生多模态看图

- 每个模型可单独选择“自动”“主模型直接看图”或“独立视觉模型”。自动模式支持 DeepSeek 官方 Flash，以及阿里云百炼 `deepseek-v4.1-flash`；其他支持图片输入的服务与模型可手动选择“主模型直接看图”。
- 原生模式将真实图片内容发送给当前主模型，支持 Chat Completions、Responses 和 Anthropic Messages 三种接口格式，可结合会话上下文连续追问。
- 新增 `view_image`，用于载入本地图片。原生模式隐藏 `analyze_image`，旧会话中的同名调用也会转为本地载图，不再额外请求独立视觉模型。
- 发送时显示当前图片处理方式与模型，便于确认实际使用的路径。
- 直接发送真实图片，不以临时随机字符识别结果拦截请求。接口拒绝图片时显示错误，不丢弃图片后静默改发纯文字。
- 保留独立视觉模型模式与按需使用的本地 OCR。

## 图片附件与会话

- 图片保存为不可变快照，后续请求校验内容完整性。图片缺失、损坏、被修改或超出大小限制时明确提示。
- 修复撤回、重试时只恢复路径文字而未携带图片的问题，多图附件可完整恢复并重新发送。
- 上传未完成时阻止发送，上传失败时显示错误。
- 图片编码仅在模型请求边界生成，不写入持久会话正文或文本摘要；上下文压缩保留图片路径，便于后续重新查看。

## Windows 更新器

- 启动安装器前先请求关闭窗口并等待 WebView2 释放文件句柄，减少更新时文件占用的机会。
- 安装器的应用关闭筛选限定为 QuickModel。

## 使用说明与验证

- 阿里云百炼请使用 `deepseek-v4.1-flash`；旧模型配置不会被自动改名。选择“主模型直接看图”要求所用服务与模型本身支持图片输入。
- 旧会话只有图片路径时，可重新附图或通过 `view_image` 载入。会话云同步目前不传输图片文件，换设备后需复制图片快照或重新附图。
- 本地 118 项自动测试通过，覆盖三种协议的图片格式、请求中的实际图片字节、错误保留、历史与快照完整性、上下文压缩及附件恢复。
- Edge 前端检查通过，覆盖模型设置保存、取消、上传状态，以及三张图片的撤回与重试；检查了 1280×900 和 900×720 视口。
- 用户已完成原生看图测试并确认正常。Windows 安装覆盖与 macOS 运行效果仍需在对应环境验证。

更新安装后请重启 QuickModel，以加载本版资源。
